## 项目概述

**言筑（WordCraft）** 是一个开源的纯前端Web应用，专注于通过自然语言对话快速生成3D空间结构模型。项目采用极简主义设计理念，强调结构参数与空间规划的准确性，而非复杂的视觉渲染。

> 🚀 **在线体验 v1.0.0**：https://joyfish666.github.io/WordCraft/（GitHub Pages，零后端、数据全在本地）

### 核心特性

- 🚀 **文生3D**：通过自然语言描述自动生成层级化空间模型
- 🎨 **极简视觉**：专注于结构与尺寸信息，无光影材质负担
- 🔧 **精准编辑**：属性面板+Gizmo辅助的双重编辑模式
- 🔒 **隐私优先**：纯前端架构，数据本地存储，用户掌控API Key
- 📤 **便捷分享**：一键生成高清设计图与数据口令
- 🌐 **开源协作**：基于GitHub的透明开发与社区贡献

### 技术亮点

- 纯前端架构，无需后端服务器
- React Three Fiber构建声明式3D场景
- Zustand轻量级状态管理
- Zod结构化数据验证
- lz-string高效数据压缩

## 基本原则与约束

- **产品形态**：Web端应用，纯前端架构，开源项目
- **数据存储**：用户对话记录、API Key与模型数据均保存在本地浏览器存储中
- **API管理**：用户自行填写大模型API Key（支持OpenAI/DeepSeek/LocalAI等兼容接口）
- **模型表达**：模型由层级化容器与子模块构成（如房屋→房间→家具）
- **视觉策略**：极简线框与色块风格，专注于展示模型结构与尺寸信息
- **用户群体**：极客用户、装修设计初学者、需要快速空间推演的从业者
- **分享机制**：通过生成带口令/二维码的高清设计图进行分享

## 功能规范

### 首页

#### 对话生成
- 用户通过自然语言描述需求（如"帮我设计一个3x3米的卧室，放一张双人床"）
- 大模型生成对应的层级化JSON数据
- 支持多轮对话，逐步完善设计细节

#### 模型展示
- **3D视角**：支持CAD式旋转/缩放/平移操作
- **2D视角**：一键切换至俯视平面图 ✅ 已实现（v1.1，见下「当前实现进度」）
- **尺寸信息展示**：选中模块时，实时在视图旁显示其长宽高及体积信息

#### 连通性检测
- 在开始对话前自动检测API Key有效性
- 异常时弹窗引导用户前往设置页排查

### 模型浏览与交互

#### 层级化模型结构
- 支持逐级下钻与回溯（整屋 → 房间 → 家具）
- 每级容器下显示其包含的子模块列表

#### 颜色标注系统
- **整屋模式**：相邻房间使用不同色块区分
- **聚焦模式**：点击进入房间后，取消房间背景色，专注于内部家具布局
- 支持在设置中切换「非色盲模式」与「色盲模式」

#### 层级路径导航
- 顶部提供面包屑路径（如：房屋 / 主卧 / 床）
- 点击任意层级可快速跳转

### 手动编辑模式（核心交互策略）

为了兼顾"参数精准度"与"操作直观性"，本功能分两个阶段实现：

#### 阶段一：属性面板（V1.0必选 - 精准控制）✅ 已实现
- **触发方式**：点击3D场景中的任意模块（家具/墙体）
- **交互界面**：右侧滑出"属性面板"
- **功能**：显示当前模块的参数（名称、长、宽、高、X/Y/Z坐标）
- **操作**：用户通过输入框修改数值，按回车或失焦后，3D场景实时更新模型形态与位置
- **优势**：符合CAD习惯，满足精确尺寸设计的硬性需求
- **附加**：支持位置微调（步长 0.1/0.5/1 米可调）、「复位位置」回到加载时快照、**撤销/重做**（工具栏按钮或 Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z）

#### 阶段二：Gizmo辅助（V2.0迭代 - 直观交互）
- **触发方式**：选中模块后，模块中心显示三维坐标轴
- **交互界面**：基于TransformControls实现的操作手柄
- **功能**：支持拖拽箭头移动物体，拖拽方块缩放物体尺寸
- **数据联动**：拖拽过程中，实时修改Zustand中的全局状态，并反向更新"属性面板"中的数值显示

### 模型管理

#### 新建/重置设计
- 一键清空当前场景数据，开始全新设计

#### 本地项目库
- 支持保存多个设计方案至浏览器本地存储（IndexedDB）✅ 已实现（v1.1）
- 支持列表查看、切换、删除、重命名操作 ✅
- 手动保存策略（工具栏「保存」+「项目库」对话框；切换/加载/清空前对有未保存修改的项目弹确认）

#### 数据导出
- 支持导出原始JSON数据，便于二次开发
- 支持导出标准化模型描述文本

### 分享与协作

#### 截图分享
- **一键截图**：点击按钮，基于当前3D视角生成高分辨率PNG图片
- **智能水印**：截图右下角自动附带当前模型的"分享口令"或二维码
- **场景净化**：截图瞬间自动隐藏辅助元素（网格、Gizmo、选中框），仅保留纯净模型结构

#### 口令机制
- 使用lz-string将JSON压缩为短口令
- 用户粘贴口令可完整还原模型数据
- 支持口令复制与历史记录

### 设置

#### API Key配置
- 支持自定义Base URL（方便使用中转服务或本地模型）
- 支持多个API Key管理与切换
- API Key连通性实时检测

#### 视觉偏好
- 切换"标准模式/色盲模式"
- 调整线框粗细与显示精度
- 自定义颜色主题

## 技术栈推荐

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 前端框架 | **React 18** | 组件化开发，生态成熟，适合开源项目 |
| 3D渲染 | **React Three Fiber** | 声明式Three.js封装，React组件构建3D场景 |
| 3D交互 | **@react-three/drei** | 提供OrbitControls（视角控制）、TransformControls（Gizmo编辑）等实用组件 |
| 状态管理 | **Zustand** | 轻量级状态管理，适合编辑器类应用的全局状态 |
| 数据验证 | **Zod** | 定义LLM输出的JSON Schema，确保数据结构正确性 |
| 本地存储 | **IndexedDB (Dexie.js)** | 存储大型模型数据和用户配置 |
| 口令压缩 | **lz-string** | 高效的JSON数据压缩算法 |
| 截图功能 | **R3F Canvas Snapshot** | 直接获取WebGL buffer生成图片，无损3D效果 |
| HTTP请求 | **Axios** | 处理API请求，支持拦截器与错误处理 |
| 构建工具 | **Vite** | 快速的开发构建工具，优化开发体验 |
| 代码规范 | **ESLint + Prettier** | 统一代码风格，提升代码质量 |
| 测试框架 | **Vitest + Testing Library** | 单元测试与组件测试 |

## 当前实现进度（截至 2026-08）

除上述路线图勾选项外，已完成以下核心能力：

- **v2 语义布局引擎**：大模型不再输出绝对坐标，而是输出「语义契约」（房间清单 + 尺寸 + 布置意图），由代码确定性平铺——
  - `auto / corridor`：走廊贯穿（东西向），房间沿两侧排列，客厅（入口）强制置于南侧并排最前
  - `auto / living`：客厅居中、其余房间环绕
  - `custom`：用户明确要求非常规布局时，保留大模型自由坐标 + 代码兜底
  - 布局模式由大模型按用户需求自动选择
- **嵌套子房间（套间卫生间）**：用户说"卧室里面有卫生间"时，卫生间渲染在**卧室内部**（不拍平为邻居）；按 `side`（north/south/east/west）靠父房间对应**角落**（贴两面墙），无提示时按常理靠东北角，位置自动约束在父房间内，**门朝父房间内部**
- **几何精确层**：整屋包围盒自动居中；家具相对房间中心、自动约束进墙内；墙体按**相邻关系分段渲染**（实体 / 门 / 开放），部分被占用的墙其余部分按外墙渲染，保证除入户门外不与外部相通
- **墙体与门**：实心地板 + 实心墙（门洞与墙同高，门墙等高）；客厅/餐厅/厨房等开放空间与走廊之间不设墙；**私密房间（卧室/书房）只连走廊、不直连厨房/客厅等开放空间**、彼此不互开门；**卫生间只与其归属房间开门**（主卧卫生间→主卧、走廊卫生间→走廊），**公共/公用卫生间**连走廊；共享墙去重并按房间标色，走廊为默认色
- **入户大门**：强制开在入口房间南侧外墙居中位置，渲染为**醒目暖色门扇 + 亮黄标识牌**（唯一与外部相通的开口）
- **视角与罗盘**：初始 45° 南视角正对入户门；方向键 / WASD 平移视角、复位视角；视口右上角**实时东西南北罗盘**（N 指向世界北）
- **交互**：点击房间进入聚焦视图（内部家具实体化、其他房间虚化）、**点击可选中房间内的部件（床等）并展示尺寸与中心坐标**、面包屑层级导航、选中模块显示尺寸 + **中心点 X/Z 坐标**
- **手动编辑（属性面板）**：点击任意模块 → 右侧滑出面板，可修改名称 / 长宽高 / X·Y·Z，回车或失焦生效、提交后自动约束进墙内；支持位置微调（步长可调）与「复位位置」回到加载时快照
- **撤销 / 重做**：基于快照的历史栈（仅会话内，上限 50 步）；工具栏按钮或 Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z；载入新模型时清空历史
- **家具常理摆放**：生成时（auto 布局）靠墙家具（床/衣柜/橱柜/书桌/沙发等）贴**最近墙**且**大面积贴墙**（长边沿墙，必要时旋转），再**沿墙滑动避开嵌套子房间**（如主卧卫生间）、**房间门口**（含入户门）与已放置的家具；独立家具（茶几/餐桌/椅子等）保持原位仅约束进墙内——代码级兜底，"床靠墙、不堵门口"不再依赖大模型遵循提示词
- **调试日志**：去重精简（纯净 JSON 回复跳过重复的解析结果、移除刷屏的入户门日志），调试面板新增「下载」按钮可保存 .log 文件
- **微调方向跟随罗盘**：默认南视角下世界 +x 投影在屏幕左侧，属性面板「东/西」按钮按罗盘映射为世界 −x / +x（北=+z、南=−z）
- **对话生成**：SSE 流式请求（兼容推理型模型长思考）、多轮修改、深度思考开关（快速/深度/跟随模型）
- **调试模式**：设置页开关，记录请求参数 / 模型原始回复 / v2 解析 / 布局平铺结果，首页面板可复制，便于向开发者复现问题
- **发布 v1.0.0**：2026-08-05 发布首个正式版本，部署至 GitHub Pages（`vite base=/WordCraft/` + GitHub Actions 自动构建部署）；86 个测试全绿、lint/build 通过
- **本地项目库（v1.1.0）**：Dexie（IndexedDB）存储多个设计方案；工具栏「保存」把当前场景写入当前项目、「项目库」对话框支持 新建/打开/重命名/删除；切换 / 加载示例 / 清空前对有未保存修改的项目弹确认；刷新后仍关联当前项目
- **2D 俯视平面图（v1.1.0）**：视口左上角「3D / 平面图」一键切换；正交俯视正北朝上、可平移缩放不可旋转、自动取景整屋；每个房间显示「名称 长×宽」标签（颜色与 3D 一致），整屋外廓显示「总长 / 总宽」尺寸线；与 3D 共享选中 / 聚焦联动
- **发布 v1.1.0**：2026-08-05 新增本地项目库与 2D 俯视平面图；测试增至 109 例全绿、lint/build 通过
- **撤销生成（对话）**：多轮修改不满意时，对话栏「撤销生成」回到本次生成前的场景并移除对应对话（生成前场景快照栈，会话内、上限 20）；生成失败不记录
- **部件点选修复**：房屋线框盒与房间选中轮廓盒不再参与射线检测——选中房间后仍可直接点选房间内家具，聚焦态也不会被误清除
